# Reel 06: 3 curvas, 3 atletas, 3 planes

## Concepto
Mostrar que atletas del mismo deporte necesitan entrenamientos completamente diferentes segun su perfil fisiologico.

## Duracion: 45 segundos

## Hook (primeros 3 segundos)
**Texto:** "Mismo deporte. Entrenamiento completamente diferente."
**Visual:** 3 curvas flash en colores distintos.

## Caption (Espanol)
3 triatletas. Mismo nivel. Misma competicion objetivo. 3 entrenamientos completamente diferentes.

Atleta A tiene buena base aerobica (LT1 alto, curva plana) pero VLamax alta. Necesita capacidad anaerobica para "limpiar" lactato mas rapido.

Atleta B tiene base aerobica debil (LT1 bajo, curva empinada temprana). Necesita volumen a baja intensidad antes de tocar intensidad.

Atleta C esta equilibrado pero necesita especificidad. Listo para potencia aerobica y trabajo de competicion.

El metodo Olbrecht lee la curva y prescribe el bloque correcto. No hay plan generico que funcione para los 3.

## Caption (English)
3 triathletes. Same level. Same target race. 3 completely different training plans.

Athlete A has a good aerobic base (high LT1, flat curve) but high VLamax. Needs anaerobic capacity work to "clear" lactate faster.

Athlete B has a weak aerobic base (low LT1, early steep curve). Needs low-intensity volume before touching intensity.

Athlete C is balanced but needs specificity. Ready for aerobic power and competition work.

The Olbrecht method reads the curve and prescribes the right block. No generic plan works for all 3.

DIAGNOSTICO

3 metricas para elegir tu bloque correcto

LT1/LT2

Ratio de umbrales

Ratio alto (>0.87) = VLamax baja.
Ratio bajo (<0.79) = VLamax alta.
Proxy fiable de glucolisis.

LT2

Nivel absoluto

LT2 vs benchmarks por disciplina.
Bajo = gap aerobico grande.
Alto = buscar potencia o capacidad anaerobica.

VLamax

Tasa glucolitica

Alta = mucho lactato producido.
Baja = motor diesel eficiente.
Determina si necesitas AEC o ANC.

EJEMPLO

LT2 bajo + VLamax alta = Capacidad Aerobica, no threshold

Atleta ejemplo: triatleta amateur

LT1: 5:45/km (FC 142)
LT2: 4:55/km (FC 168)
Ratio: 0.74 → VLamax alta
LT2 nivel: bajo para su prueba

Intuicion dice

"Haz threshold para subir LT2"

Resultado: mas lactato, mas fatiga, no mejora

Olbrecht dice

"Capacidad aerobica primero"

Bajar VLamax con volumen LT1. Luego threshold.

Entrenar threshold con VLamax alta es como construir el segundo piso sin cimientos. Primero hay que reducir la produccion de lactato (AEC), luego mejorar su eliminacion (threshold).

Olbrecht, J. (2000). The Science of Winning. Mader, A. (2003). Eur J Appl Physiol, 88, 297–316.

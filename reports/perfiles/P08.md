## Casos limite

### CL1: Atleta que ya supera objetivo
El sistema detecta que LT2 (4:30/km) > objetivo HM (5:41/km). Gap negativo. Deberia sugerir objetivo mas ambicioso. PARCIALMENTE IMPLEMENTADO: el motor fisiologico nota gap negativo pero no genera sugerencia de nuevo objetivo automaticamente.

### CL2: Variabilidad muy baja como senal de estabilidad
Todas las tomas de Z2: 0.9-1.1. Variabilidad <0.2. stability_score >0.90. El sistema tiene alta confianza. Para atleta masters, esta estabilidad refleja anhos de entrenamiento consistente.

### CL3: Tempo progresivo (S9) como mini-test informal
3 puntos a 3 velocidades diferentes replican la curva del test formal. El motor los integra como 3 puntos independientes. Juntos, aportan informacion equivalente a un mini-test de 3 escalones. La interpolacion multi-bracket puede usar estos puntos como brackets para LT2p. FORTALEZA del sistema: las tomas de entreno con velocidades variadas son mas informativas que tomas repetidas a la misma velocidad.

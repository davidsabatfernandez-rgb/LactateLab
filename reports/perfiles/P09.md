## Casos limite detallados

### CL1: Tomas contradiciendo test formal (S2 vs Test 1)
- Test 1: esc1 = 1.2 a 6:00/km. Toma S2: 1.4-1.5 a 6:00/km. Similar pero no contradictorio.
- Test 1: esc2 = 2.8 a 5:00/km. No hay toma directa a 5:00/km para comparar.
- La contradiccion principal: las tomas de Z2 muestran que el baseline real es ~1.0-1.2 y el LT1 esta ~1.5-1.7, no 2.8.
- El motor no puede "invalidar" un test formal, pero pondera por quality/protocol_score. Las tomas ayudan a corregir parcialmente.
- LIMITACION: el ajuste es conservador. Un mecanismo de "invalidacion de test con confianza baja cuando datos subsiguientes lo contradicen" seria util.

### CL2: Mejora de protocolo entre tests
- Test 1 (4 esc, protocol 0.52) -> Test 2 (7 esc, protocol 0.85) -> Test 3 (8 esc, protocol 0.90).
- A S14, contribucion de Test 1: recency=0.2, protocol=0.52, weight total ~0.08 por punto. Marginal.
- A S14, contribucion de Test 2: recency=exp(-56/18)=0.04 -> 0.2, protocol=0.85. Weight ~0.14 por punto.
- A S14, contribucion de Test 3: recency=1.0, protocol=0.90. Weight ~0.65 por punto.
- El sistema naturalmente "olvida" tests antiguos y deficientes. CORRECTO pero lento en las primeras semanas.

### CL3: Prescripcion contaminada S1-S6
- Entre Test 1 (S1) y Test 2 (S6), el sistema usa parcialmente el LT1 sobreestimado (2.8 mmol, ~5:00/km).
- Si el entrenador prescribe Z2 basada en LT1p del sistema (~5:00/km), la atleta estaria corriendo en Z3 real (~5:00/km vs LT1 real ~5:40/km). No peligroso pero suboptimo.
- Las tomas de S2 (1.4-1.5 a 6:00/km) deberian activar warning: "Tomas de entreno sugieren LT1 mas bajo que test formal. Considerar retest con protocolo mejorado."
- MEJORA POSIBLE: anadir warning automatico cuando tomas de Z2 dan valores significativamente menores que los predichos por el test.

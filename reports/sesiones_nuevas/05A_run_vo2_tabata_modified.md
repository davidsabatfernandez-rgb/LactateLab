# run_vo2_tabata_modified

**Tipo:** Z5 VO2max intervalos cortos
**Disciplina:** Running
**public_label:** "VO2 Tabata modificado (20''/10''x8 bloques)"

## Descripcion

Bloques de 8 repeticiones 20''/10'' a velocidad VO2max. 2-3 bloques con 3' recuperacion entre bloques.

## Dose Ladder

| Step | Descripcion | Tiempo util |
|---|---|---|
| 1 | 2 bloques x 8x(20''/10'') D:3' | 5.3 min |
| 2 | 3 bloques x 8x(20''/10'') D:3' | 8 min |
| 3 | 3 bloques x 10x(20''/10'') D:3' | 10 min |
| 4 | 4 bloques x 8x(20''/10'') D:3' | 10.7 min |

## Parametros

- **fatigue_cost:** 5
- **session_role:** key
- **compatible_block_types:** aerobic_power_block

## Justificacion cientifica

T@VO2max >7 min es optimo (Frontiers 2024 HIIT categorization). Tabata modificado acumula tiempo en VO2max con alta densidad. Mayor adherencia que intervalos largos para principiantes (Poon 2024).

## Perfiles beneficiados

- P01 (principiante): intervalos cortos menos intimidantes que 4x4'
- P05 (estancamiento): estimulo neuromuscular diferente
- P06 (joven glucolitico): formato compatible con alta VLamax

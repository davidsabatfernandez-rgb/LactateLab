# tri_brick_z2_transition

**Tipo:** Brick triatlon (bike->run)
**Disciplina:** Triatlon
**public_label:** "Brick Z2 transicion bike->run"

## Descripcion

45-60' bici Z2 + T2 rapida + 15-30' running Z2. Formato introductorio de brick para principiantes y base_early.

## Dose Ladder

| Step | Descripcion | Tiempo util |
|---|---|---|
| 1 | 45' bici Z2 + T2 + 15' run Z2 | 60 min |
| 2 | 60' bici Z2 + T2 + 20' run Z2 | 80 min |
| 3 | 75' bici Z2 + T2 + 25' run Z2 | 100 min |
| 4 | 90' bici Z2 + T2 + 30' run Z2 | 120 min |

## Parametros

- **fatigue_cost:** 3
- **session_role:** key
- **compatible_block_types:** aerobic_capacity_block, threshold_development_block

## Justificacion cientifica

Bricks cada 10-14 dias facilitan la adaptacion neuromuscular sin coste excesivo (USA Triathlon). El formato Z2 es seguro para principiantes y permite practicar T2.

## Perfiles beneficiados

- P03 (Ironman): brick base para fases tempranas
- P06 (joven glucolitico): adaptacion neuromuscular bike->run
- P07 (ciclista -> triatleta): aprender la transicion T2
